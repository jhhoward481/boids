# boids

Hi!

Description:
In this project, I created a boids algorithm that will summon some bird-oid (boid) objects, and demonstrate how they flock together with the tweaking of certain parameters. These boids can then generate a triangulation of the viewing plane, being used as points in a set to generate a Delaunay triangulation. A variety of user controls allow the user to generate something pretty, fun, or scary, with the attempt of producing simple screen-saver-like effects. Math done behind the scenes; graphics generation done in WebGL.

Directions:
I used VSCode's Live Server extension, opening the boids/shell directory to run the code in browser. To the right are controls and a variety of presets the user can select.
